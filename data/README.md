# Data — One Curb, One Case (DATA step)

Source: **Cambridge, MA Commonwealth Connect (SeeClickFix / Open311)**
dataset `2z9k-mv9g`, pulled via the Socrata SoQL API.
License: ODC PDDL (public domain), adopted Feb 2024. Attribution: SeeClickFix.
No API key is used by this step (the Tinker key is only needed later).

Generated by `src/pull_data.py`. All numbers below come from the real pull;
none are fabricated. Reproducible with `random_seed = 20261011`.

## Exact query

```
GET https://data.cambridgema.gov/resource/2z9k-mv9g.json
  $select = ticket_id,issue_type,issue_description,address,ticket_created_date_time
  $where  = issue_type in('Sidewalk Defect','Sidewalk Obstruction',
            'A-Frame/Business Sidewalk Obstruction','Botanical Obstruction',
            'Traffic/Pedestrian Signal Complaint')
            AND length(issue_description)>40
  $limit  = 50000
Header: User-Agent: Mozilla/5.0
```

to one side only, so duplicate complaints about the same spot cannot cross the
split (leakage guard). Rows with a blank address fall back to their own
`ticket_id` as the group key.

## PII scrubbing

`issue_description` free text is scrubbed for high-confidence PII before any row
is written:

- emails → `<email>`
- phone numbers → `<phone>`
- named-reporter intros ("my name is …", "reported by …", sign-offs) → `<name>`
- leading house number before a street name → `<num>`

Audited across all 500 sampled rows: **0 descriptions contain an email, phone
number, or a house-number-before-street pattern**; 77 rows carry a scrub
placeholder. The structured `address` column is left intact — it is the
official civic location a public-works crew needs to find the barrier, not
free-text PII.

## Held-out rows carry NO gold yet

`heldout.raw.jsonl` deliberately contains only the raw fields
(`ticket_id, issue_type, issue_description, address, ticket_created_date_time`).
Missing-evidence gold must be hand-written by a human before any model sees a
held-out note. This DATA step stops at that boundary.
